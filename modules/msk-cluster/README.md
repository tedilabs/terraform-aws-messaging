# msk-cluster

This module creates following resources.

- `aws_msk_cluster`
- `aws_msk_configuration`
- `aws_msk_scram_secret_association` (optional)
- `aws_security_group` (optional)
- `aws_security_group_rule` (optional)
- `aws_secretsmanager_secret` (optional)
